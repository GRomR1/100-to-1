# «100 к одному» — приложение ведущего

Клавиатурное приложение для показа телеигры на одном экране: табло, счёт, озвучка.
Мышью пользоваться нельзя и не нужно — всё на клавишах. Картина всегда 1280×720 и масштабируется под окно.

Визуальная спецификация экранов — в Sketch-макете ([DESIGN.md](DESIGN.md), `100k1.sketch`),
механика работы с самим макетом — в [AGENTS.md](AGENTS.md).

## Запуск

`node` и `pnpm` в этом окружении лежат вне `PATH` — они из mise. Пакеты ставит только `pnpm`, `npm` не используется.

```bash
export PATH="$HOME/.local/share/mise/shims:$PATH"
pnpm install
pnpm dev                      # http://localhost:5173
```

Для показа:

```bash
pnpm build && pnpm preview --port 4173 --strictPort
# или одной командой, с caffeinate, чтобы экран не гас:
pnpm kiosk
```

Порядок действий ведущего перед выпуском:

1. Заполнить [`src/data/questions.yaml`](src/data/questions.yaml) — см. раздел «Данные выпуска» ниже.
2. Запустить приложение и открыть его на проекцию/второй монитор в полный экран (`F`).
3. Нажмите любую клавишу: первый же нажатый ключ разблокирует звук (браузер не даёт играть mp3 до жеста пользователя).
4. Состояние (фаза, счёт, открытые строки) переживает перезагрузку страницы — оно в `localStorage`.
   `R` с меню или после игры обнуляет всё до нуля.

## Данные выпуска: `src/data/questions.yaml`

Файл читается при сборке (`?raw`), поэтому **его нужно заполнить до старта**: после правки
в `pnpm dev` страница перезагрузится сама, для `preview` требуется пересборка. Ошибку в формате
приложение покажет на отдельном экране с перечнем проблем — играть с ним нельзя, надо исправить YAML.

```yaml
teams: [Команда 1, Команда 2]

rounds:
  - mode: simple                 # Простая игра, ×1
    question: Что всегда лежит на кухонном столе?
    rows:
      - { text: "Хлеб", points: 60 }
      - { text: "Молоко", points: 50 }
      # ... всего 6 строк
  - mode: double                 # Двойная игра, ×2
    question: Что есть в любом доме?
    rows: [ ... 6 строк ... ]
  - mode: triple                 # Тройная игра, ×3
    question: На чём можно доехать до работы?
    rows: [ ... 6 строк ... ]
  - mode: vice-versa             # Игра наоборот
    question: Что берут с собой на пляж?
    rows:
      - { text: "Ласты", points: 240 }
      # ... 6 строк, сверху вниз от дорогого ответа к дешёвому
  - mode: big                    # Большая игра: табло не используется
```

Что проверяет валидация:

| Поле | Требование |
|---|---|
| `teams` | ровно две команды, имена не должны совпадать |
| `rounds` | хотя бы один раунд; `mode` — один из `simple`, `double`, `triple`, `vice-versa`, `big` |
| `rows` | ровно 6 строк в каждом раунде, кроме `big`; текст непустой, очки — целое положительное число; тексты внутри раунда уникальны |
| `question` | обязателен в `vice-versa`, опционален в остальных |

Порядок элементов в `rows` — это порядок строк на табло сверху вниз: первая строка открывает клавиша `1`,
последняя — `6`. Очки вписываются как на карточке; множитель режима приложение применяет само.

`question` нигде на экран не выводится: вопрос читает ведущий. Поле нужно, чтобы текст вопроса был
под рукой у того, кто готовит выпуск, и чтобы валидация не пропускала раунд «наоборот» без вопроса.

Раунды идут строго по списку. `big` должен стоять последним, а если большой игры в выпуске нет — просто удалите строку.

## Правила

Раунды: **Простая ×1 → Двойная ×2 → Тройная ×3 → Игра наоборот → Большая игра**. Множитель умножает очки
строки, открытой в этом раунде.

### Простая, двойная, тройная

- `Enter` на заставке раунда — табло (`button.mp3`). Ход при этом ещё не разыгран.
- Розыгрыш идёт на табло: `A` — первая команда, `B` — вторая. Без звука, только бейдж команды становится ярче.
- До выбора команды строки не открываются, а `X` даёт лишь звук промаха — крестики не загораются.
- Выбравшая команда называет ответы. Верный — открыть строку клавишей `1`–`6` по номеру карточки: очки строки,
  умноженные на множитель, сразу идут её счёт и в банк раунда, звучит «правильный ответ».
- Неверный — `X`: загорается крестик **только этой** команды, звук промаха.
- Три промаха подряд этой команды → фаза шанса: соперница получает **один** ответ. `1`–`6` верно — банк раунда
  и очки открытой строки переходят к ней; `X` — её крестик, банк остаётся. После этого ход не переходит.
- Если команда открыла все 6 строк, не успев трижды промахнуться, банк остаётся у неё.

### Игра наоборот

- На заставке `Enter` — и сразу табло с шестью закрытыми строками; 20 секунд идёт обсуждение (`big-game-timer.mp3`).
- Первой отвечает команда с **меньшим** счётом.
- `1`–`6` открывают строку — это **не** начисляет очки и **не** звучит.
- Попадание фиксирует отдельная клавиша: `A` — первой команде, `B` — второй. Начисляются очки последней
  открытой ещё не засчитанной строки + «правильный ответ».
- **Ответ у команды один за раунд.** После засчитанного попадания `A`/`B` этой команды больше ничего
  не начисляют и не озвучивают: сколько бы строк ни оставалось неразыгранными.
- Мимо — `X`, только звук, без механики. Крестиков и шанса в этом режиме нет.
- Последняя карточка остаётся засчитываемой и после того, как открыты все шесть.

### Большая игра

Играют только победители по сумме четырёх раундов — счёт виден на меню перед ней.

- `Enter` на меню → заставка правил (`big-game.mp3`) → `Enter` → экран таймера.
- Два игрока команды-победительницы. Первый отвечает на 5 вопросов за **15 секунд**, второй — те же вопросы за **20 секунд**.
- `Enter` запускает таймер и `big-game-timer.mp3`; `Enter` во время работы останавливает оба;
  следующий `Enter` запускает второго игрока, а после второго — завершает игру.
- Совпавший ответ: `X` → `big-game-same-answer.mp3`, игрок предлагает другой вариант. Больше `X` ничего не делает.
- Время вышло → `alarm-clock.mp3`.
- Очки после большой игры ведущий считает руками: приложение показывает обычное меню с прежним счётом,
  ничего не начисляет.
- `Enter` с этого меню — `closing.mp3`, выпуск окончен. `R` — полный сброс: счёт ноль, снова простая игра.

### Конец раунда

Раунд **не завершается сам**. Когда табло открыто (или шанс разыгран), на поле жмётся `Enter` — это
итог раунда (`round.mp3`) и экран с итогами. Второй `Enter` — следующий раунд и его интро. Раньше времени
`Enter` игнорируется, чтобы случайное двойное нажатие не уводило ведущего с табло в меню.

## Клавиши

| Экран | Клавиши |
|---|---|
| Меню | `Enter` — начать выпуск / большая игра / финал · `R` — сброс |
| Заставка раунда | `Enter` — на табло (розыгрыш хода там же) · `Enter` — наоборот (20 с обсуждения) и большая игра (к таймеру) · `Esc`/`M` — меню |
| Табло: розыгрыш хода | `A`/`B` — кто забирает ход (без звука) · `X` — звук промаха, кресты не загораются |
| Табло (простая/двойная/тройная, шанс) | `1`–`6` — открыть строку · `X` — промах · `Enter` — итог раунда · `T` — меню с очками поверх табло |
| Табло «наоборот» | `1`–`6` — открыть строку без очков · `A`/`B` — засчитать попадание (по одному на команду за раунд) · `X` — звук промаха · `Enter` — итог · `T` — меню |
| Таймер большой игры | `Enter` — старт/стоп/второй игрок/финал · `X` — совпавший ответ |
| Итоги раунда | `Enter` — следующий раунд · `M`/`Esc` — меню |
| После большой игры | `Enter` — `closing.mp3` · `R` — начать заново |
| На любом экране | `F` — полный экран |

## Звуки

Файлы лежат в `public/audio/` (kebab-case).

| Что происходит | Файл |
|---|---|
| Интро режима | `simple-game.mp3` · `double-game.mp3` · `triple-game.mp3` · `vice-versa-game.mp3` · `big-game.mp3` |
| Вход на табло — перед розыгрышем хода | `button.mp3` |
| Строка открыта с очками / попадание | `answer-correct.mp3` |
| Промах | `answer-wrong.mp3` |
| Итог раунда | `round.mp3` |
| 20 секунд обсуждения, таймер большой игры | `big-game-timer.mp3` (глушится, когда отсчёт остановлен или истёк) |
| Совпавший ответ в большой игре | `big-game-same-answer.mp3` |
| Время вышло | `alarm-clock.mp3` |
| Выпуск окончен | `closing.mp3` |

## Устройство кода

```
src/engine/      чистый движок: типы, правила (множители, BIG_SECONDS), reducer — без React
src/input/       keymap: клавиша + фаза → событие движка
src/audio/       менеджер 14 треков и таблица «переход фазы → звук»
src/data/        questions.yaml + zod-схема
src/screens/     Menu, Intro, Field, BigGame
src/stage/       Stage: 1280×720 с масштабом под окно
src/store.ts     Zustand + persist в localStorage
```

Состояний движка: `Menu`, `Intro`, `TeamPlay`, `Chance`, `VicePlay`, `BigPlay`, `ScoreUpdate`, `Final`, `Closed`.
Какие клавиши во что превращаются — зависит от фазы и режима, полная таблица в `src/input/keymap.ts`.
